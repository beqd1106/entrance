## 3. 説明文（4000字以内）

```
「そのお店のルールが分からない」を、なくすアプリです。

麻雀を打てるようになっても、初めての雀荘に行くのは勇気がいります。
白ポッチって何？ 北を抜くとどうなる？ アリスってどのタイミング？
——ルールが分からないまま席に着くのが不安で、一歩を踏み出せない。

JANDOORは、お店ごとのハウスルールをそのまま読み込んで、
CPU3人との対局で「先に打ってみる」ことができるアプリです。


■ お店ごとにルールが変わります

同じアプリなのに、選ぶお店のルールによって、
使う牌も、点数の数え方も、祝儀も、対局の空気も変わります。

・四人麻雀／三人麻雀
・赤牌・金牌・青牌の枚数
・白ポッチ（オールマイティ牌）
・アリス／チューリップ（和了時に牌をめくるルール）
・割れ目、オープンリーチ、焼き鳥、トビ賞
・北抜き、華牌（春夏秋冬）とそれぞれの効果
・サイコロチャンス
・お店独自の特殊牌（牌ごとに違う効果）
・ローカル役（大車輪・三連刻・人和など）
・東天紅系の独自点数体系


■ 「違うところ」だけ教えてくれます

ルール表を全部読む必要はありません。
「一般的なルールと違うのはこの項目だけ」という形で表示されるので、
初めてのお店でも、覚えることは最小限で済みます。


■ ルールは自分でも作れます

持ち点、ウマ、赤牌の枚数、特殊牌の効果まで、
プログラミングなしで自由に設定して対局できます。
矛盾した設定は自動でチェックされます。


■ 安心して遊べる設計です

・現金や賞品を賭ける機能はありません
・ポイント（BP）はゲーム内専用で、換金・交換はできません
・アプリ内課金・広告はありません
・通信しないので、機内モードでも遊べます
・個人情報を一切収集しません


■ 横向きで遊べます

iPhoneを横に持つと、卓・河・手牌・操作ボタンがすべて1画面に収まります。


※ アプリに登場する店舗はすべて架空です。
```

## 7. 審査メモ（App Review Information → Notes）

```
本アプリは、麻雀のローカルルール（ハウスルール）を学ぶための一人用アプリです。

【賭博性がないことについて】
・現金、賞品、電子マネー等を賭ける機能はありません。
・対局結果に応じて金銭・景品・割引等を付与する機能はありません。
・アプリ内に登場する「BP（ボーナスポイント）」はゲーム内専用の数値であり、
  換金・譲渡・売買・景品との交換は一切できません。UI上にも「非換金」と明記しています。
・賭け金の設定、レート（金額）の表示はありません。
・利用者同士の対戦機能・通信機能はなく、対戦相手はすべてCPUです。

【通信について】
アプリの動作に必要な通信は行いません（すべての処理が端末内で完結します）。
店舗情報に含まれるSNSリンクを利用者がタップした場合のみ、Safariが起動します。

【アカウント】
ログイン機能はないため、デモアカウントは不要です。

【登場する店舗について】
アプリ内の店舗（DEMO雀荘 四麻館ほか）はすべて架空であり、実在の店舗ではありません。

【画面の向き】
卓を広く表示するため、横向き専用としています。
```

## 8. TestFlight の「テスト内容」（What to Test）

```
横向きにしてお試しください。

1. ホーム →「デモ店舗」から店を選ぶ
2. 店舗ページの「このルールで遊んでみる」をタップ
3. CPU3人と対局（打牌は牌をタップ）

見ていただきたい点：
・お店を変えるとルールが実際に変わること（五等サンマ館は三麻・華牌あり）
・「一般ルールとの差分」表示が分かりやすいか
・横持ちで操作しづらい箇所がないか
・牌が見やすいか

※ポイント（BP）はゲーム内専用の数値で、換金はできません。
```

## 9. スクリーンショット

**横向き専用アプリのため、スクリーンショットも横向きで登録します。**

| 必須サイズ | 解像度（横） | 用途 |
| --- | --- | --- |
| 6.9インチ | 2868 × 1320 | iPhone 16 Pro Max 等（必須） |
| 6.5インチ | 2688 × 1242 | iPhone 11 Pro Max 等（必須） |
| 13インチ iPad | 2064 × 2752 → 横は 2752 × 2064 | iPad対応にする場合 |

推奨する5枚の構成：

| # | 画面 | 添えるコピー |
| --- | --- | --- |
| 1 | 五等サンマ館での対局中 | その店のルールで、行く前に打てる |
| 2 | 店舗ページのルール差分表示 | 違うのは、この19項目だけ |
| 3 | 特殊牌の一覧（この店の特別な牌） | 白ポッチも、アリスも、華牌も |
| 4 | 和了結果（役・BP・アリスめくり） | 何が起きたか、その場で分かる |
| 5 | ルールエディタ | お店が、自分でルールを作れる |

### 生成済みのスクリーンショット

```
store-assets/appstore/6.9inch/01〜04.png   （2868 × 1320）
store-assets/appstore/6.5inch/01〜04.png   （2688 × 1242）
store-assets/raw-*.png                      （元画像：956 × 440）
```

作り直す場合は `store-assets/README.md` の手順を参照してください。

> 生成の注意（過去の知見）：**画像は1枚ずつアップロードして順序を確定**させること。
> LINE等で受け渡すと圧縮されるため、必ず元データを使うこと。
> より高精細にしたい場合は、Xcodeのシミュレータ（iPhone 16 Pro Max・横向き）で
> `⌘S` で撮ると等倍のスクリーンショットが得られます。
