## 1. いちばん大事な前提

**サーバが無くてもアプリは完全に動く。**

`web/config.js` の `window.HOUSERULE_API` を空文字にすれば、
これまでどおり端末内（localStorage）だけで完結する。
対局・ルール編集・店舗ページ、すべて動く。

```js
// web/config.js
window.HOUSERULE_API = '';   // ← 空にするとサーバを使わない
```

デモを配るとき、ネットワークの無い場所で見せるとき、
費用を完全にゼロにしたいときは、ここを空にすればよい。
サーバは「あれば便利」の位置づけで、依存させない。

## 2. 構成

```
ブラウザ / iOSアプリ
    │
    ├─ API Gateway (HTTP API)          5 req/s に絞る
    │      └─ Lambda  houserule-api    Node22 / arm64 / 512MB / 15秒
    │             ├─ DynamoDB  houserule-main   オンデマンド・1テーブル
    │             └─ Bedrock   Claude Haiku 4.5  ルールの下書き生成
    │
    └─ S3  houserule-assets-720936371817
           非公開。読み書きとも署名付きURL経由のみ（表示用は15分で失効）
```

API Gateway を挟んでいるのは **絞り（スロットリング）が要るから**。
Lambda の関数URLだと誰でも無制限に叩けてしまい、費用が読めなくなる。

### 経路

| メソッド | パス | 認証 | 用途 |
| --- | --- | --- | --- |
| GET | `/health` | 不要 | 疎通確認 |
| GET | `/stores` | 不要 | 公開中の店舗一覧 |
| GET | `/stores/{id}` | 不要 | 店舗1件（プロフィール＋ルール） |
| PUT | `/stores/{id}` | 編集キー | 保存 |
| POST | `/stores/{id}/photo-url` | 編集キー | 写真アップロード用の署名付きURL |
| POST | `/stores/{id}/play` | 不要 | 体験プレイを1件記録 |
| POST | `/stores/{id}/checkin` | 不要 | 来店を1件記録 |
| GET | `/stores/{id}/stats` | 不要 | 集計値 |
| POST | `/rules/draft` | 不要 | 文章からルール設定の下書き |

### DynamoDB の持ち方（1テーブル）

| pk | sk | 中身 |
| --- | --- | --- |

## 3. 費用の見込み

デモ〜小規模（月1万リクエスト程度）を想定した概算。

| サービス | 単価の考え方 | 月あたり |
| --- | --- | --- |
| Lambda | 100万リクエスト/月まで無料枠 | ほぼ0円 |
| API Gateway | 100万リクエストあたり約$1.0 | 〜2円 |
| DynamoDB | オンデマンド。読み書きした分だけ | 〜10円 |
| S3 | 保管 約$0.025/GB＋転送（非公開・署名付きのみ） | 〜30円 |
| CloudWatch Logs | 保存期間7日に制限済み | 〜20円 |
| Bedrock (Haiku 4.5) | 1回の下書きで0.5円前後 | 使った分だけ |

**合計：通常は月100円未満。** 2万円の枠に対して桁が2つ違う。

枠が効いてくるのは、想定外に呼ばれたときだけ。そのために下記の歯止めを入れている。

### 歯止め

| 仕組み | 設定 | 効き方 |
| --- | --- | --- |
| **自動遮断（いちばん重要）** | $20 超過で Lambda の課金権限を自動剥奪 | **止まる** |
| API Gateway のスロットリング | 5 req/s・バースト10 | 入口で止める |
| ↳ AI下書きの経路だけ | 1 req/s・バースト2 | 単価の高い経路を強く絞る |
| 全体の1日上限 | 下書き50／書込500／記録5000／画像URL2万 | IPを変えても抜けられない天井 |
| 相手ごとの1日上限 | 記録50・下書き10 | ふつうの連打を弾く |
| S3 の公開 | **していない**（署名付きURLのみ・15分） | 転送量の青天井を塞ぐ |
| Lambda の同時実行 | アカウント上限10 | 同時に走る数の上限 |
| CloudWatch Logs の保存期間 | 7日 | ログ代がじわじわ増えない |
| S3 の未完了アップロード削除 | 3日 | 中断した分が残り続けない |
| 予算アラート | $130（≒2万円）／50・85・100% でメール | 気づける |

### 自動遮断のしくみ

予算 `cost-circuit-breaker`（$20 ≒ 3,000円）を超えると、AWS Budgets Action が
**承認を待たずに** Lambda 実行ロールへ拒否ポリシー `houserule-cost-freeze` を付ける。
これで Bedrock・DynamoDB・S3・Logs のすべてが使えなくなり、課金が止まる。

- 対象は Houserule が使う6サービスのみ（EC2 など無関係の資源では誤作動しない）
- 発動しても Web/iPhone アプリ自体は動き続ける（`config.js` を空にしたのと同じ状態になる）
- 解除は付いたポリシーを外すだけ

```bash
# いま遮断されているか
aws iam list-attached-role-policies --role-name houserule-api-role
# 解除する
aws iam detach-role-policy --role-name houserule-api-role --policy-arn arn:aws:iam::720936371817:policy/houserule-cost-freeze
```

Bedrock は1回ずつが軽いが、唯一「使った分だけ」課金なので二重に絞ってある。
相手ごとに1日10回、サービス全体では1日50回まで（`server/index.mjs` の `DAILY`）。
全体の上限は環境変数 `DAILY_DRAFT` などで変えられる。

## 4. 手順

### コードを直したら

```bash
node test/run-server-tests.js     # 署名と入力の絞り込みを検証
node scripts/deploy-api.mjs       # server/ を Lambda へ反映
```

### 店舗データを入れ直す

`src/data/stores.js` を正として流し込む。

```bash
HOUSERULE_API=https://<api>.execute-api.ap-northeast-1.amazonaws.com \
ADMIN_TOKEN=<管理キー> \
node scripts/seed-api.mjs
```

### いまの費用を見る

```bash
aws ce get-cost-and-usage --time-period Start=$(date -u +%Y-%m-01),End=$(date -u +%Y-%m-%d) \
  --granularity MONTHLY --metrics UnblendedCost \
  --group-by Type=DIMENSION,Key=SERVICE --output table
```

### 止めたいとき

費用をゼロにするだけなら、**まず `web/config.js` を空にする**（アプリは動き続ける）。
資源そのものを消す場合は次のとおり。消すと店舗データも消える。

```bash
aws apigatewayv2 delete-api --api-id <api-id>
aws lambda delete-function --function-name houserule-api
aws dynamodb delete-table --table-name houserule-main
aws s3 rm s3://houserule-assets-720936371817 --recursive
aws s3api delete-bucket --bucket houserule-assets-720936371817
aws iam delete-role-policy --role-name houserule-api-role --policy-name houserule-api-access
aws iam delete-role --role-name houserule-api-role
```

## 5. 権限の考え方

Lambda に与えているのは、この用途に要るものだけ。

| 対象 | 許可 |
| --- | --- |
| DynamoDB | `houserule-main` テーブルのみ |
| S3 | `houserule-assets-…/photos/*` のみ |
| CloudWatch Logs | 自分のロググループのみ |
| Bedrock | `InvokeModel` のみ |

管理者権限は渡していない。仮に Lambda のコードに問題があっても、
触れる範囲がこの4つに限られる。

### 書き込みの守り方

- 読み取りは誰でも。書き込みは店舗ごとの **編集キー** が要る
- まだ誰のものでもない店舗IDは、最初に触った人にキーが発行される
- 保存してよい項目は allowlist で固定。`editToken` などは上書きできない
- 文字列の長さ・数値の範囲・配列の件数をすべて検査する
- AIが返した内容も同じ扱い。一覧にない項目は採用しない

## 6. このアカウントで動いている別の資源

Houserule とは関係なく、**EC2 インスタンス `i-08fab59f6cef22dce`（t3.micro / 名前 "udemy"）が
2026-04-05 から動き続けている**。VPC の料金と合わせて月 $8.6（約1,300円）ぶんの利用があり、
いまはクレジットで相殺されて請求額に出ていない。クレジットが尽きると実費になる。

使っていないなら停止すると費用が止まる（ディスクは残るので、あとで再開できる）。

```bash
aws ec2 describe-instances --instance-ids i-08fab59f6cef22dce --query 'Reservations[].Instances[].State.Name'
aws ec2 stop-instances --instance-ids i-08fab59f6cef22dce   # 停止（データは残る）
```

Houserule の自動遮断はこの EC2 を対象にしていない。誤って学習環境を止めないため。
