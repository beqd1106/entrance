# 特殊牌・特殊効果・ローカルルール 拡張仕様書

> 本書は「既知の代表的な特殊ルールを広くカバーし、未知の店舗独自ルールにも拡張できる設計」を定義するものです。
> 麻雀のローカルルールは地域差・店舗差が非常に大きいため、**完全網羅ではありません**。
> 特定店舗のルールを転載せず、「その系統を再現できるエンジン」として実装しています。

---

## 0. 調査の情報源と信頼度の区分

| 区分 | 内容 | 本設計での扱い |
| --- | --- | --- |
| **公式情報** | 麻雀のルール（Wikipedia）、プロ団体の競技規定、ネット麻雀の公開ルール | 既定値の根拠として採用 |
| **店舗公式情報** | 雀荘公式サイトのルールページ、店内掲示 | 系統の骨格として参照。数値はそのまま採用しない |
| **個人ブログ・note等の実践記録** | 五等サンマ／ロケット三麻／東天紅の実践者記事 | **参考値**として採用し、設定で変更可能にする。標準として断定しない |
| **ローカルルールまとめ（Wiki系）** | 麻雀ローカルルールWiki 等 | 用語と分類の把握に使用。数値は要確認 |
| **推定・要確認情報** | 流派差が大きく確定できない項目 | READMEの「置いた仮定」に明記し、ヒアリングで差し替える前提 |

今回の追加調査で新たに確認した主な事実：

- **東天紅**：一五九萬以外の萬子を除いた28種112枚。一萬・五萬・九萬・北がガリ（抜きドラ）。常に東場。
  点数の単位が「翻」ではなく「点」。**出アガリは1人分、ツモは2人分**の収入。役満は50点。
  前局の和了者が次局の親。ノーテン罰符は場に10点。統一ルールがなく地域・店舗差が大きい（要確認）。
- **ロケット系三麻**：東天紅の点数体系に、金牌・ロケット牌・華牌効果・常時ドラ2枚を足したインフレ三麻。
  「点数を1/1000した値が得点」「40符固定」「1翻でも倍満に昇格」「本場1本＋5点」。
  祝儀は一発・裏・金・白ポッチが各+5点、ロケット牌+20点、本役満+15点など（実践者記録・要確認）。
- **五等サンマ系**：35,000点持ち40,000点返し／萬子2〜8抜き／常時ドラ2枚／5筒5索が金金赤赤／
  華牌（春＝即時祝儀、夏＝打点1ランクアップ、秋＝5がダブドラ、冬＝アリス）／サイコロチャンス。
  店により**ツモ損の有無・親流れ・祝儀額が大きく異なる**（要確認）。
- **宝石牌（Jewel型）**：牌ごとに異なる効果（ドラ+2／祝儀+n／オールマイティ／翻数倍化など）を持つ体系。
- **アリス／チューリップ**：アリスはドラ表示牌の隣をめくって手牌と一致すれば祝儀、一致する限り継続。
  チューリップは「現物＋その両隣」まで一致扱いにする拡張。

### F. 特殊牌（本サービスの中心）

```json
{
  "id": "amethyst5p",
  "name": "アメジスト5筒",
  "tile": "5p",
  "count": 1,
  "color": "blue",
  "activationTiming": "win",
  "stacking": "sum",
  "description": "リーチ後はオールマイティ牌として使え、和了に含めるとBPを5獲得します。",
  "effects": [
    { "type": "bonus", "value": 5 },
    { "type": "almighty" }
  ],
  "conditions": { "riichiOnly": true }
}
```

**効果（effects）**

| type | 内容 |
| --- | --- |
| `dora` | ドラ +n |
| `han` | 翻数 +n |
| `bonus` | ゲーム内ポイント +n（祝儀相当） |
| `rankUp` | 打点ランクアップ（満貫→跳満→…） |
| `scoreMultiply` | 点数 ×n |
| `bonusMultiply` | 獲得ボーナス ×n |
| `almighty` | オールマイティ牌として和了に使える |
| `doubleDora` | 指定牌をダブルドラ化 |
| `alice` / `tulip` | アリス／チューリップを発動 |
| `dice` | サイコロチャンスを発動 |
| `yakuman` | 役満扱い |
| `ura` | 裏ドラ +n |

**発動タイミング（activationTiming）**：`win`（和了時）／`draw`（ツモった瞬間）／`always`（手牌にあるだけ）

**条件（conditions）**：門前限定／リーチ時限定／ツモ限定／ロン限定／一発時限定／副露時無効／
`combo`（複数の特殊牌が揃った時のみ）

**重複（stacking）**：`sum`（枚数分加算）／`once`（何枚あっても1回）

### G. 白ポッチ・特殊白

枚数／扱い（ボーナスのみ／オールマイティのみ／両方）／オールマイティ条件（常時／ツモ時／リーチ後ツモ時）／
使用時BP／ドラ扱いの有無。**白としても使える**点は常に成立（牌タイプは白のまま）。

### H. アリス・チューリップ

有効／門前条件／リーチ必須／ツモ限定／ツモ・ロン倍率／開始位置／めくる順番／一致対象（手牌／和了牌）／
一致条件（同一牌／現物＋両隣）／継続／最大めくり枚数／刻子の扱い／一致1枚あたりのBP・点棒／上限。
華牌「冬」や特殊牌の効果からも発動できます。

### I. 花牌・華牌・抜き牌

春夏秋冬それぞれに効果（即時BP／打点ランクアップ／5牌ダブドラ／アリス発動／ドラ+n／翻+n）。
引いた瞬間に自動で抜けて即補充。抜いた華牌をドラに数えるかも設定可能。
北以外の抜き牌（ガリ）は `sanma.extraNukiTiles`、残す萬子は `sanma.manzuKeep` で指定します。

### J. インフレ三麻ビルダー

「五等サンマ」「東天紅」「ロケット三麻」を**固定実装していません**。
次の組み合わせで系統を作ります。

```
使用牌（manzuKeep / removeManzu / flowers / specialTiles）
  × 点数体系（scoring.mode / flat.*）
  × 抜き（northMode / extraNukiTiles / kita*）
  × ドラ（indicators / bakuDora / attributeDora）
  × 祝儀（bonus.* / dice / alice）
  × 順位（rankOnly / shizumiUma / umaZeroSum）
```

### K〜O

ボーナス（非換金）／サイコロ・イベント／割れ目（全員割れ目・本場除外・決め方）／
オープンリーチ（公開範囲・ダブル・放銃罰）／店舗運用の検索軸は、それぞれ設定項目として実装済みです。

## 5. MVP後に回すもの

| 項目 | 理由 |
| --- | --- |
| パオ（責任払い）の点数分配 | 発生頻度が低く、実装コストに対し体験への影響が小さい |
| 時間打ち切り・途中抜け・代走 | オンライン対戦フェーズの要件 |
| 十三不塔などの配牌時役の厳密判定 | 配牌時点の状態保持が必要 |
| 形式テンパイ非採用時の厳密判定 | 役の有無を含めた判定が必要 |
| ドラ表示牌が特殊牌だった場合の引き直し | 設定項目のみ用意し、挙動は未実装 |
| 賞品・景品連携 | **法務リスクが高いため、MVPでは意図的に非対応** |
| 全国ランキング報酬 | 同上 |

## 6. 専用ロジックが必要なもの（Builderでは吸収できない）

| 項目 | 理由 |
| --- | --- |
| 点数体系そのものの差し替え（東天紅系） | 支払い分配の構造が違うため、ScoreEngineに分岐が必要 |
| オールマイティ牌 | 和了判定に牌の置換探索が必要 |
| アリス・チューリップ | 王牌のめくり列という物理構造への依存がある |
| 抜き牌（北・ガリ） | 手番の行動として選択肢生成が必要 |
| 華牌の自動抜きと補充 | ツモ処理そのものに割り込む |
| ローカル役の形状判定 | 手牌の構造解析が必要（述語として実装） |
| 割れ目 | 支払い計算の全経路に係数がかかる |

## 7. House Rule Builder（WHEN / IF / THEN）で吸収できるもの

コードを触らずに設定だけで追加できるもの：

- 「特定牌を含んで和了したらBP+n」
- 「リーチ＋一発＋特定牌でBP大量」
- 「特殊牌を3種そろえたら打点ランクアップ＋サイコロ」
- 「四北かつ四華でBP+20」
- 「親のツモ和了なら翻+1」
- 「割れ目のときだけボーナス倍」

```json
{
  "name": "オールスター（特殊牌3種以上）",
  "when": "win",
  "if": [
    { "fact": "hasSpecial", "id": "blue5s" },
    { "fact": "hasSpecial", "id": "silver5p" },
    { "fact": "hasSpecial", "id": "emerald5m" }
  ],
  "then": [
    { "action": "bonus", "value": 10 },
    { "action": "rankUp", "value": 1 },
    { "action": "dice" }
  ]
}
```

**WHEN**：`win` / `draw` / `kyokuStart` / `kan` / `kita` / `flower`
**IF**：`hasTile` / `hasSpecial` / `menzen` / `tsumo` / `ron` / `riichi` / `ippatsu` / `han` / `yakuman` / `dealer` / `kita` / `flower` / `always`
**THEN**：`bonus` / `han` / `dora` / `rankUp` / `points` / `dice` / `message`

| --- | --- | --- |
| **高** | 祝儀・チップの実金額表示 | **実装しない**。BP（非換金）のみ |
| **高** | 対局結果に応じた景品・割引の付与 | **実装しない** |
| **高** | ポイントの換金・譲渡・売買 | **実装しない** |
| **高** | レート表記（点ピン等） | **掲載しない** |
| 中 | サイコロチャンス等の射幸性が高い演出 | 非換金BPに限定。上限（cap）を必須化 |
| 中 | イベント報酬 | ゲーム内称号・バッジのみ |
| 中 | オンライン成績と実店舗特典の連動 | **直結させない**（来店回数など行動ベースに限定） |
| 低 | 来店スタンプ・チェックイン | 記録のみ・報酬なし |

Rule Validator に安全側のチェックを組み込んであり、ポイントのラベルに「非換金」の記載がない場合は警告を出します。
**法的な最終判断は必ず弁護士等の専門家に確認してください（要専門家確認）。**

### ■ 追記セクション：特殊牌・特殊効果・ローカルルール拡張

**方針**
既知の代表的な特殊ルールを広くカバーし、未知の店舗独自ルールにも拡張できる設計にすること。
特定店舗のルールを丸写しせず、「その系統を再現できるルールエンジン」として実装すること。
麻雀のローカルルールは地域差・店舗差が大きいため、**完全網羅を主張しないこと**。
確定できない仕様は仮定を置き、READMEに明記してヒアリングで差し替えられるようにすること。

**1. 点数体系そのものを差し替え可能にする**
`scoring.mode = 'standard' | 'flat'` を設け、東天紅・ロケット三麻のような
「ロン＝1人分／ツモ＝2人分」「点数を1/1000した値が得点」「符固定」「1翻でも倍満に昇格」
「役満は固定点」という体系を、通常ルールと同じエンジンで再現できるようにすること。

**2. 特殊牌を完全にデータ化する**
1牌ごとに次を設定可能にすること。
対象牌／枚数／色・デザイン／名称／説明文／発動タイミング（和了時・ツモった瞬間・手牌にあるだけ）／
発動条件（門前・リーチ時・ツモ・ロン・一発・副露時無効・他の特殊牌との組み合わせ）／
重複時の扱い（枚数分加算・1回のみ）／効果（ドラ+n／翻+n／BP+n／打点ランクアップ／点数×n／
ボーナス×n／オールマイティ化／ダブルドラ化／アリス発動／チューリップ発動／サイコロ発動／役満扱い／裏ドラ+n）。
例：**アメジスト5筒 ＝ 祝儀5枚相当のBP＋リーチ後オールマイティ**が設定だけで表現できること。

**3. ローカル役を採用可否・翻数つきで設定可能にする**
大車輪／大数隣／大七星／三連刻／四連刻／一色三順／三風刻／五門斉／紅孔雀／百万石／人和／十三不塔／八連荘 等を
組み込み述語として持ち、店舗が「採用する／しない」「翻数 or 役満」を選べるようにすること。
三連刻と一色三順のように**同じ牌姿の別解釈になる役**は、その旨を警告できること。

**4. ドラの種類と重みを拡張する**
赤・金・青・星・虹の属性を持たせ、**属性1枚あたり何枚分のドラか**を設定可能にすること（金＝ドラ2枚分など）。
爆ドラ（表ドラ表示牌の追加めくり）、全赤・全金（同一牌4枚すべてに属性を付与）、永久ドラ、
ドラ表示牌が花牌・特殊牌だった場合の処理を設定可能にすること。

**5. 抜き牌（北・ガリ）を一般化する**
北以外（一萬・五萬・九萬など）も抜き牌にできること。残す萬子を選択可能にすること（東天紅は1m・5m・9m）。
抜きで一発が消えるか、抜き後のツモが嶺上開花になるか、抜いた牌でロンできるか、
手牌で使えるか（常時／役満のみ／不可）を設定可能にすること。

**6. 割れ目・オープンリーチを詳細化する**
割れ目：倍率／決め方（サイコロ・親固定・ランダム）／全員割れ目／ノーテン罰符・本場点・リーチ棒の除外。
オープンリーチ：追加翻／BP／公開範囲（全手牌・待ち牌のみ）／ダブルオープン／放銃時の罰則。

**7. イベント卓を定義可能にする**
`events: [{ id, name, enabled, note, ruleOverrides }]` の形で、
日替わり・イベント卓・初心者卓・配信卓が既存ルールを部分的に上書きできる構造にすること。

**8. 検索軸に追加する**
オールマイティ牌／爆ドラ／ローカル役／東天紅系／全赤／金牌／特殊牌の有無で店舗を検索できること。

**9. すべてのボーナスは非換金**
祝儀・チップに相当するものは、すべてゲーム内専用の非換金ポイントとして実装すること。
実金額表示・換金・景品交換・対局結果に応じた金銭報酬は**実装しないこと**。
サイコロチャンス等の射幸性の高い演出には上限（cap）を必ず設けること。
**法務判断は断定せず、必ず「要専門家確認」と明記すること。**

**10. テストを必ず追加する**
新しい特殊牌・ローカル役・点数体系を追加した場合は、
（a）単体テスト（効果が正しく計算されること・条件が効くこと）、
（b）全プリセットのCPU自動対局による整合性テスト（牌の増減・点棒総和・進行停止）
を必ず追加してから完了とすること。
