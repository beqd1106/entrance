# 提案資料（PowerPoint）構成案 — 全20枚

**想定：対面20分（説明12分＋実機デモ5分＋質疑3分）／画面共有でも可**

デモは資料の途中（15枚目）ではなく、**5枚目のあと**に差し込むのが最も効きます。
「話を聞く姿勢」から「自分ごとで考える姿勢」に切り替わるためです。

## 2. 企画の一言概要

- **メッセージ**：その店のルールで、行く前に打てる。
- **本文案**：
  - 全国の雀荘が、それぞれのハウスルールを設定した「オンライン支店」を持つ
  - ユーザーは来店前に、その店のルールでCPU対戦を体験できる
  - 目的はオンライン麻雀ではなく、**実店舗への送客**
- **図解案**：中央に大きく「その店のルールで、行く前に打てる。」／下に「店を知る → ルールで打つ → 来店する」の3ステップ矢印。
- **話す内容**：
  「一言で言うと、行く前にその店のルールで打てるサービスです。
  雀魂と戦うつもりはありません。**雀魂で覚えた人が、実店舗デビューする時に開くアプリ**を狙います。」

## 3. 背景・課題

- **メッセージ**：初来店を止めているのは「強さ」ではなく「分からなさ」。
- **本文案**：
  - ユーザー：ルールが分からない／失敗が怖い／雰囲気が分からない／練習する場がない
  - 店舗：新規が入らない／説明コストが高い／ルールの個性が伝わらない／オンライン施策の手段がない
- **図解案**：左にユーザーの吹き出し4つ、右に店舗の吹き出し4つ。中央に「情報の断絶」。
- **話す内容**：
  「初心者が来ない理由は、弱いからではありません。
  **白ポッチって何？　北を抜くとどうなるの？** が分からないまま席に着くのが怖いんです。
  一方で店側は、毎回口頭で説明していて、その個性が集客に使えていない。」

## 4. 既存サービスの課題

- **メッセージ**：「ルールで探して、ルールで試す」ができるサービスが存在しない。
- **本文案**：

  | | ネット麻雀（雀魂・MJ等） | 雀荘検索サイト |
  | --- | --- | --- |
  | ルール | 標準固定・ローカル非対応 | テキスト記載のみ（未記載も多い） |
  | 体験 | できるが**その店のルールではない** | できない |
  | 目的 | 長く遊ばせる | 情報を引く |

- **図解案**：2つの円が重ならず、その隙間に「JANDOOR」を配置。
- **話す内容**：
  「ネット麻雀は標準ルールしか扱いません。検索サイトはルールを書いてあるだけ。
  **ローカルルールという最大の個性が、集客資産になっていない**のが今の状態です。」

## 5. 目指す体験

- **メッセージ**：「読む」ではなく「打つ」。それが来店の背中を押す。
- **本文案**：店を発見 → ルールを見る → **ハウスルールを体験する** → 雰囲気を知る → 交流する → 来店する
- **図解案**：横一列の6ステップ。3番目だけを大きく強調し「ここが中心」と注記。
- **話す内容**：
  「ルールは読ませても頭に入りません。でも、1回打てば分かります。
  この3番目を作ることが、このサービスの本体です。──ここで実物をお見せします。」

> **▼ ここで実機デモ（3〜5分）**
> 1. 普通の四麻を1局 → 2. 店舗を切り替えてルール変更 → 3. アリス発動 →
> 4. エディタで特殊牌を追加 → 5. 五等サンマ館のルール説明 → 6.「このルールで遊ぶ」→ 7. 華牌効果

## 6. サービスコンセプト

- **メッセージ**：オンラインは目的ではなく、店の「入口（ドア）」。
- **本文案**：
  - 全国の雀荘が、自分のルールを設定した支店をオンラインに持つ
  - ユーザーは無料。店舗は月額
  - オンラインでの勝敗に価値を持たせない（**非換金・ゲーム内専用**）
- **図解案**：中央に実店舗、周囲にオンライン支店。矢印はすべて実店舗へ向かう。
- **話す内容**：
  「オンラインで長く遊ばせる必要はありません。**来店したら成功**です。
  だからこそ、賭博性のある設計も要りません。」

- **図解案**：実画面のスクリーンショットを4枚並べ、間を矢印でつなぐ。

## 8. 雀荘側のメリット

- **メッセージ**：ルールの個性が、そのまま集客資産になる。
- **本文案**：
  1. 新規客の不安を来店前に解消できる
  2. ルール説明の時間が減る（スタッフの工数削減）
  3. 独自ルールが検索対象になり、**指名で見つけてもらえる**
  4. 設定するだけで、お客様向けの説明文が自動生成される
  5. 来店数を数字で把握できる（QRチェックイン）
  6. SNSに貼れる「体験できるURL」が手に入る
- **図解案**：6項目のアイコン付きカード。左に「今」右に「JANDOOR導入後」のBefore/After。
- **話す内容**：
  「一番大きいのは3番です。『白ポッチのある店』『五等サンマができる店』で探されて、
  指名で来てもらえるようになります。これは今どこにもない導線です。」

## 9. ユーザー側のメリット

- **メッセージ**：初来店の不安が、1半荘で消える。
- **本文案**：
  - 知らないルールを、失敗できる場所で先に試せる
  - 一般ルールとの「違うところだけ」が分かる
  - 店の雰囲気・スタッフ・料金が事前に見える
  - 特殊ルールで店を探せる（今までできなかった）
- **図解案**：不安の吹き出しが、体験を通って小さくなる図。
- **話す内容**：
  「『恥をかきたくない』という気持ちが、一番の障壁です。
  それを、誰にも見られない場所で1回打つことで消してしまう。」

## 10. 差別化ポイント

- **メッセージ**：ルールが「文章」ではなく「動くデータ」であること。
- **本文案**：
  1. 店の設定を変えるだけで、対局挙動・点数・祝儀・説明文がすべて変わる
  2. ゲーム側に店名の分岐が1つもない（＝店の追加はデータ1件）
  3. 未知のハウスルールも設定で追加できる（WHEN/IF/THEN）
  4. 一般ルールとの差分だけ見せる
  5. 説明文の自動生成／矛盾チェック内蔵
- **図解案**：左「一般的な作り方＝店ごとに作り直し」／右「JANDOOR＝1つのエンジン＋設定データ」。
- **話す内容**：
  「ここが技術的な肝です。普通に作ると、店が増えるたびに作り直しになります。
  最初からルールをデータにしておいたので、2店舗目以降は**設定を1件足すだけ**です。」

## 11. ハウスルール体験の価値

- **メッセージ**：同じアプリなのに、店ごとに打ち味が変わる。
- **本文案**：CPU自動対局による実測（同一コード・設定違いのみ）

  | ルール | 平均打点 | 特徴 |
  | --- | --- | --- |
  | 競技ルール風（赤なし） | 2.47翻 | 祝儀なし・堅い |
  | 一般四麻（赤3枚） | 3.27翻 | 標準 |
  | 特殊牌館 | 4.40翻 | 特殊牌・割れ目 |
  | 五等サンマ館 | 6.90翻 | 華牌・北抜き・常時ドラ2 |
  | 花牌重視五等 | 8.19翻 | 秋のダブドラで跳ね上がる |

- **図解案**：横棒グラフ（平均打点）。右端に「同じコード・設定だけの違い」と注記。
- **話す内容**：
  「設定を変えるだけで、平均打点が2.5倍まで変わります。
  **これがそのまま『店ごとの打ち味の違い』**です。数字で説明できるのは強みだと思っています。」

## 16. 五等サンマ・特殊牌まで対応できること

- **メッセージ**：一番難しいルールが動くなら、他は全部動く。
- **本文案**：
  - 五等サンマ系：35,000持ち40,000返し／萬子2〜8抜き／常時ドラ2枚／北抜き／完全順位制＋沈みウマ／ツモ損切替
  - 華牌エフェクト：春＝即時ボーナス／夏＝打点ランクアップ／秋＝5牌ダブドラ／冬＝和了時アリス
  - 特殊牌：牌ごとに異なる効果（ドラ+n／翻+n／ボーナス／オールマイティ／組み合わせ役）
  - サイコロチャンス：個数・発動条件・ゾロ目／ピンゾロ倍率・上限
  - **1店舗の再現ではなく、その系統を作れるエンジンとして実装**
- **図解案**：春夏秋冬の牌4枚と、それぞれの効果を線でつないだ図。
- **話す内容**：
  「五等サンマ系は、麻雀のルールの中でも特に複雑な部類です。
  ここが動くように作ってあるので、たいていのハウスルールは設定だけで表現できます。」

## 18. 法務・運用リスク

- **メッセージ**：先に安全側で設計してあります（ただし専門家確認は必須）。
- **本文案**：
  - 論点：賭博罪／換金性ポイント／景品表示法／資金決済法／風営法／未成年／依存／不正／個人情報
  - MVPで実装しないもの：現金・賭け金・換金ポイント・送金・払い戻し・実金額表示
  - 実装するもの：**非換金のゲーム内ポイント**、来店スタンプ・称号（記録のみ・報酬なし）
  - オンラインの成績と店の実利益を**直結させない**
  - **法的判断は要専門家確認**
- **図解案**：赤（やらない）と緑（やる）の2列リスト。
- **話す内容**：
  「ポイントという言葉は扱いが難しいので、最初から換金の概念を作らない設計にしています。
  ただし、最終的な判断は必ず弁護士の先生にご確認ください。」
